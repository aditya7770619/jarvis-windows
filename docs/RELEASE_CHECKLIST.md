# Release checklist

## Source alpha
- [x] Document project status and limitations.
- [x] Include source code, dependency pins, MIT licence, privacy notes, and security guidance.
- [ ] Confirm Windows dependency compatibility on a clean machine.
- [ ] Integrate dashboard and voice runtime into one application lifecycle.
- [ ] Validate hand tracking and camera lifecycle on Windows hardware.
- [ ] Integrate and hardware-test air drawing mode.

## Windows installer
- [ ] Select and validate a frozen-app architecture.
- [ ] Build installer from a clean Windows environment.
- [ ] Test install, launch, microphone permission, camera use, standby, stop, and uninstall.
- [ ] Publish checksums and release notes.
- [ ] Sign installer when code-signing is available.

Do not mark unchecked items complete without evidence.
