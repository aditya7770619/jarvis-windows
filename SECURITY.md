# Security policy

JARVIS is an early-stage desktop project. It can generate mouse and keyboard input and access camera and microphone devices. Use it only on a computer you control, review the code before running it, and keep a reliable way to stop the process.

Do not publish exploit details in public issues. If GitHub private vulnerability reporting is enabled, use a private security advisory. Otherwise contact the maintainer privately before disclosure.

No security response-time guarantee is offered for this pre-release project.
